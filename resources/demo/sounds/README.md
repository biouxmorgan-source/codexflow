# Sons de la campagne de démonstration

Un fichier déposé ici remplace l'ambiance que le code synthétise. Le nom du fichier est la clé du son,
avec l'extension `mp3`, `ogg`, `m4a` ou `wav`. Les sons sont joués en boucle.

Le dépôt est public : n'ajoutez que des sons dont vous détenez les droits et que vous acceptez de
publier sous la licence du projet.

| Fichier | Contenu | Scènes |
| --- | --- | --- |
| `tide` | Marée basse sur les marches | La troisième lanterne, Les perches déplacées, La salle aux six lits |
| `mist` | Brume de Pierrecendre | Les perches déplacées, Le carnet de Mornevent, Ce qui remonte |
| `storm` | Orage sur le phare | La cave du phare, Le serment refondu |
